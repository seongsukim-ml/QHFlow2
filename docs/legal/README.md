# Licensing and release documentation

QHFlow2 uses file-level licensing. The repository-root [`LICENSE`](../../LICENSE),
[`REUSE.toml`](../../REUSE.toml), and [`LICENSES/`](../../LICENSES/) directory
remain in their standard locations for GitHub and REUSE tooling.

Supporting material is organized here:

- [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md): upstream attribution
- [`PROVENANCE.md`](PROVENANCE.md): file-classification audit and evidence
- [`DATASETS.md`](DATASETS.md): dataset licenses and redistribution guidance
- [`RELEASE_MANIFEST.yaml`](RELEASE_MANIFEST.yaml): release inventory and
  sidecar status
- [`templates/`](templates/): dataset and checkpoint metadata templates
- [`third_party_licenses/`](third_party_licenses/): verbatim upstream license
  notices distributed with QHFlow2
