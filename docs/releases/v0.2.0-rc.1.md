# QHFlow2 v0.2.0-rc.1

This **code prerelease** makes the corrected SO(3) and O(3) architectures and
QH9Stable Muon training configurations available under a versioned source tag.
Retrained benchmark checkpoints and detailed results will follow after training
and evaluation; they are not included in this release.

## Included

- **QHFlow2-s/m/l/xl (order-fixed):** corrected eSCN/e3nn component ordering,
  QH9 AO coordinate alignment, spectral/gated nonlinearities, and per-atom
  matrix/time conditioning.
- **QHFlow2-O(3)-s/m/l/xl:** identity/inversion group averaging with shared
  parameters and gradients through both evaluations.
- **QH9Stable random-split training:** Muon starts at **1e-3**; norm, embedding,
  and non-matrix parameters use AdamW at **1e-4**. No warmup; cosine decay and
  per-size gradient accumulation settings are provided.
- **PySCF Q tensors:** Psi4 is no longer required.
- **Version metadata:** code version, Git commit/dirty state, and model identity
  in new checkpoints; a dependency-free version CLI and versioned preparation
  reports.

## Legacy behavior and the convention bug

The feature-ordering bug arose in QHFlow2 while adapting conventions from prior
models. Follow-up experiments reported similar performance after the ordering
correction; this observation is not a completed benchmark of the newly added
SO(3)/O(3) Muon models. Detailed results are planned with their retrained release.

Legacy model names and default configs remain available in `main` for checkpoint
reproducibility. Corrected architectures use distinct names and require new
training. A matching tensor shape does not make old weights a valid conversion.
The historical `ver.0.1.0` tag is preserved unchanged. Pin `v0.2.0-rc.1` for this
source snapshot rather than a moving development branch.

## Validation and remaining work

The complete release suite passes **67 tests**, including nine new source-version
and checkpoint-compatibility checks. Tests cover proper/improper rotations, AO
conventions, gradients, native optimizer agreement, resume, Git/source archives,
and loading checkpoints with and without release metadata. The prior model
preparation also passed CPU optimizer steps for all eight variants on real
QH9Stable samples and a Lightning training/validation smoke test.

Full retraining and benchmark evaluation have not started. GPU memory and
throughput have not been profiled; XL has approximately 930 million parameters.
No new checkpoint weights are attached to this release.
