Each archive includes:

- `weights.ckpt`: unchanged model tensors, resolved saved configuration, code provenance and checkpoint step; optimizer/scheduler state is omitted.
- `config.yaml`: the exact resolved training configuration, including the original dataset paths. Override those paths for your machine.
- `CHECKPOINT_METADATA.yaml` and `metrics.json`: model counts, source commit and checkpoint hash, official split hash/counts, test metrics and training-cost evidence.
- `README.md`, `LICENSE.txt` and `SHA256SUMS`: loading instructions, checkpoint license notice and integrity checks.

These are inference exports. Original checkpoints with optimizer/scheduler state
are retained in the training outputs for exact continuation. The weights use
CC-BY-NC-SA-4.0, as specified by the repository's existing QH9 checkpoint policy;
source-code licenses are unchanged.

## Loading

Use the [tested Stable/Muon environment](../QH9STABLE_MUON.md#stable-data-and-runtime)
with QHFlow2's `src` on the Python import path:

```python
import torch
from omegaconf import OmegaConf
from pl_module import get_pl_model

checkpoint_file = "/absolute/path/to/weights.ckpt"
checkpoint = torch.load(checkpoint_file, map_location="cpu", weights_only=True)
conf = OmegaConf.create(checkpoint["hyper_parameters"]["conf"])
model = get_pl_model(conf)(conf)
model.load_state_dict(checkpoint["state_dict"], strict=True)
model.eval()
```

All four exports passed this CPU loading path and tensor-by-tensor exact equality
against their source checkpoints. This packaging check does not rerun the test
set; reported metrics come from the completed runs' recorded full-test evaluation.
