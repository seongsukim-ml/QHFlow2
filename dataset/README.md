# Download datasets separately

Full dataset payloads and generated caches are excluded from Git. A small
[three-molecule test fixture](../examples/qh9stable/README.md) is included
separately for loading and checkpoint smoke tests. Follow the
[QH9 download instructions](../README.md#dataset) and
[Stable/Muon data preparation](../docs/QH9STABLE_MUON.md#stable-data-and-runtime)
for the current benchmarks. Checkpoints are available separately on
[Hugging Face](https://huggingface.co/ksusu/QHFlow2-QH9).

The legacy water example uses the original
[SchNOrb water archive](https://quantum-machine.org/data/schnorb_hamiltonian/schnorb_hamiltonian_water.tgz).
Download and extract it into the raw directory of your selected external dataset
root. The archive contains `schnorb_hamiltonian_water.db`; processed tensors and
LMDB shards are generated by the existing dataset loaders. On the shared SC26
workspace, place durable data below `/dataset/seongsu/shared-home/datasets/` and
set the dataset root in your configuration.

The loaders and their processing logic remain in
[`ori_dataset.py`](../src/dataset_module/ori_dataset.py) and
[`md17_datasets_shard.py`](../src/dataset_module/md17_datasets_shard.py).
The previously bundled water data/caches were removed from all published branch
and tag histories in the [2026-10-28 cleanup](../docs/history/2026-10-28-cleanup.md).
